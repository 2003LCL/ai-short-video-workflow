# Roadmap

## Stage 1: Local POC

- Generate storyboard from shop info.
- Support 1-5 images.
- Export captions, voiceover text, plan JSON, GIF, and HTML preview.
- Add a basic medical risk-word gate.

## Stage 2: Real AI Generation

- Add LLM provider config through environment variables.
- Replace template generation with model-based script and storyboard generation.
- Add structured JSON validation and retry.

## Stage 3: Audio and Video Rendering

- Add CozyVoice as the primary TTS path.
- Add FFmpeg export for MP4.
- Add BGM, caption burn-in, and platform-specific aspect ratios.

## Stage 4: Operator Workflow

- Add a review dashboard.
- Add customer/project records.
- Add manual approval states: draft, review, revision, ready, published.

## Stage 5: Business Version

- Add vertical templates for dental, beauty, food, repair, education, and local services.
- Add data feedback: views, completion rate, comments, leads.
- Add weekly content calendar generation.
