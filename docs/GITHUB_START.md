# GitHub Account and Upload Guide

## Create an Account

1. Open `https://github.com`.
2. Click `Sign up`.
3. Enter email, password, and username.
4. Verify your email.
5. Enable two-factor authentication in account settings.

## Recommended Username

Pick a clean name you can use on resumes and project pages. Avoid random numbers if possible.

Examples:

- `yourname-ai`
- `yourname-labs`
- `yourname-dev`

## Create the Repository

1. Click `+` in the top-right corner.
2. Choose `New repository`.
3. Repository name suggestion: `ai-short-video-workflow`.
4. Choose `Public` if this is for portfolio display.
5. Do not add another README on GitHub because this project already has one.

## Upload Safely

Before uploading:

- Do not upload `.env`.
- Do not upload API keys.
- Do not upload real customer materials.
- Do not upload private medical or patient-related content.
- Keep demo images and generated demo output only.

If you use Git locally, `.gitignore` already excludes the risky files.
